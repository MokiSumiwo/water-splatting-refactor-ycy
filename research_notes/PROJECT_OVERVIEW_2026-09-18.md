# 水下三维重建与去水体渲染：项目整体情况

整理日期：2026-09-18。实验信息截至 2026-09-17。

本文面向首次接触项目的读者，介绍项目要解决什么问题、目前采用什么方法、已经取得什么结果，以及哪些问题仍然没有解决。插图均来自本项目实际保存的渲染结果，不是示意生成图。

## 1. 项目目标

本项目基于 **WaterSplatting、Nerfstudio 和三维高斯泼溅（3D Gaussian Splatting，简称 3DGS）**，从同一水下场景的多张照片中学习一个三维模型。

这个模型需要同时完成两件事：

1. **带水体的新视角渲染**：换到没有参与训练的相机位置，生成一张看起来像真实水下照片的图像。它应当正确重现物体、水体颜色、衰减和雾化效果。
2. **去水体渲染**：在同一个三维模型中移除显式建模的介质影响，显示模型估计的物体外观。它不是对照片直接做一次二维滤镜增强。

目前的研究目标是：**保留 BND 带来的有界颜色和较好的前景去水视觉效果，同时提升带水体新视角指标，争取接近 BND OFF 的水平；进一步改善远景去水效果。**

项目已经能够完成上述两类渲染，但还没有同时解决带水指标、远景偏色和远处高斯残留，也没有充分证据宣称达到当前最先进水平（SOTA）。

可以从图中看到：

## 3. 模型是怎样工作的

### 3.1 用许多高斯表示场景

3DGS 用大量带有位置、尺度、方向、不透明度和颜色的小型三维分布表示场景。这些分布通常被称作“高斯点”或“高斯球”，但它们实际可以是被拉伸、旋转的椭球，并不是实体小球。

渲染时，每个高斯投影到图像上形成一个软边的椭圆色块，再按前后关系进行叠加。大量合适的高斯可以形成清晰表面；位置、尺度或颜色不合适的高斯，也可能形成浮片、条纹或模糊斑块。

本项目同时学习一个介质模型，用来表示水对物体光线的衰减，以及水体自身带来的散射背景。

### 3.2 带水图和去水图的区别

以下公式是帮助理解的简化形式，不是实际多层渲染器的完整公式：

```text
带水图像 ≈ 物体外观 × 透射率 + 水体散射贡献
去水图像 ≈ 使用已学到的高斯颜色和不透明度，移除显式介质项后合成
```

“透射率”可以理解为物体光线经过水体后还保留多少。光程越长，通常越难从照片中观察到物体本身的颜色与细节。

关键困难在于：**如果水体的颜色或雾化效果已经被模型错误地存进高斯的颜色、形状或不透明度里，只关闭显式介质项不会自动清除这些内容。**这解释了为什么带水照片拟合得较好，去水结果却仍可能出现偏色和高斯残留。

但这只是可能的机制解释。当前还不能逐一断言哪些高斯一定表示了水、哪些一定表示了真实远处物体。

### 3.3 为什么同一张照片会有多种解释

例如，一个远处物体在照片中较暗，模型可能通过以下不同组合解释它：

- 物体本身颜色较暗；
- 水体衰减较强；
- 物体距离较远；
- 物体覆盖不足或不透明度较低。

这些因素共同变化后，带水图像可能仍很接近真实照片，却对应不同的去水结果。这种“不同参数解释同一观测”的问题称为**可辨识性不足**。它是本项目的主要研究困难之一。

## 4. 当前主要模块

| 模块 | 通俗解释 | 目前的作用与边界 |
|---|---|---|
| M1 | 让介质网络同时考虑观察方向、图像位置和相机位置 | 提高介质表达能力；也可能让介质记住某些视角，增加物体颜色与介质之间的补偿 |
| OCMC | 限制相机相关介质变化中缺少观测支持的部分 | 控制 M1 的部分自由度；有实验收益，但不等于恢复了真实水质 |
| CICA | 从多个训练视角汇集颜色修正证据，约束高斯基础颜色的比例 | 主要作用于基础颜色 DC，不直接修几何或介质；有小幅带水指标收益，远景去水改善仍不充分 |
| BND | 将每个高斯的方向相关 RGB 限制在 `[0,1]` | 避免无上界颜色参与补偿；有利于控制异常颜色，但不保证物理分解正确 |
| FSB | 将基础颜色与随视角变化的颜色分量分开，再用有界映射组合 | 在保留 BND 的同时调整颜色表达方式；目前保留的 BND ON 外观候选，收益较小且有场景依赖 |

DC 可以理解为一个高斯的基础颜色；SH 是表示颜色随观察方向变化的一组系数。读者不需要理解其数学细节，只需知道模型既有“基础颜色”，也有“随视角变化的颜色”。

当前两条参考路线是：

```text
带水指标历史参考：M1 + OCMC + CICA，BND OFF，Auxiliary OFF
当前有界研究路线：M1 + OCMC + CICA + FSB，BND ON，Auxiliary OFF
```

这里的“保留”指作为后续研究的对照，不代表仓库所有历史脚本的默认配置都相同。不同实验还可能使用不同 renderer backward 或 CICA 导数版本，复现时应以各实验协议和 checkpoint 元数据为准。

### BND ON 和 OFF 各有什么取舍

传统 BND OFF 的高斯颜色没有相同的上界，能够利用更大的颜色范围拟合带水照片，但这也可能掩盖不合理的介质／颜色分解。BND ON 限制了这种补偿自由度，保留了项目希望维持的有界性和前景视觉表现，但部分场景的带水指标较低。

**不能把这种取舍写成“BND ON 必然更真实”或“BND OFF 必然更准确”。**有界颜色只是一个约束；较高的带水 PSNR 也只表示更接近带水照片。两者都不直接证明真实去水颜色正确。

## 5. 数据和指标怎样理解

项目使用 SeaThru-NeRF 水下场景数据及相机标定信息。近期完整评估固定覆盖四场景的全部 13 个测试视图。

| 场景 | 测试视图数 | 本文重点观察 |
|---|---:|---|
| Curasao | 3 | 前景去水效果明显，远处边界和水域仍有不自然残留 |
| IUI3-RedSea | 4 | 远景观测衰减较强，蓝色残留和深度分散值得关注 |
| JapaneseGradens-RedSea | 3 | 远景偏灰蓝，水域上方可见大色块、黑区和拖影 |
| Panama | 3 | 近景颜色细节较丰富，但部分视图远水区域存在明显青蓝斑块和条纹 |

`JapaneseGradens` 沿用数据目录中的拼写。某些早期诊断使用的训练相机数量、筛选方式不同，不能混作同一个统计样本。

| 指标 | 大致含义 | 正向方向 |
|---|---|---|
| PSNR | 生成图与真实照片的像素误差，单位 dB | 越高越好 |
| SSIM | 图像局部结构是否相似 | 越高越好 |
| LPIPS | 神经网络特征上的感知差异 | 越低越好 |
| MSE | 平均像素平方误差 | 越低越好 |

以上指标在本项目中评估的是**带水新视角图像**。不存在可直接报告的真实去水 PSNR。四场景均值通常先对场景内的测试视图取平均，再对四个场景等权平均。

历史结果有不同 LPIPS 实现、显示映射和训练起点，不能把不同日期的表直接拼成统一排行榜。先计算每张图 PSNR 再平均，也不等于先平均 MSE 再转成 PSNR。

## 7. 当前最重要的两个视觉问题

### 7.1 问题一：去水体后的远处偏色与模糊

**表现：**近处珊瑚的纹理、明暗和颜色区分较明显；远处表面仍像覆盖了一层青蓝或灰紫色，层次不足，细节模糊。它不是简单的“整张图去水不够”，而是去水效果随距离、区域和场景明显变化。

![JapaneseGradens 远景偏色与高斯残留定位](assets/project_overview_20260917/02_japanese_far_problems.png)

**图 2：JapaneseGradens 的问题定位。**黄色 A 框是远景表面，右上给出带水和去水的同位置局部图；红色 B 框是水域上方的异常大色块。前景纹理较清楚，并不意味着远景已经得到同样充分的恢复。

现有证据支持三类因素共同参与：

1. **远景颜色观测减弱。**经过更长光程后，训练照片对远处高斯颜色的约束较弱。模型可以拟合带水外观，却仍不能确定其去水后的颜色。
2. **介质与物体颜色互相补偿。**部分水体色调可能进入物体颜色，或者物体颜色变化被介质变化抵消。去掉显式介质后，这些颜色不会自动消失。
3. **几何、多层混合与视角外观问题。**同一像素可能混合多个深度层；错误表面、遮挡边界和方向相关颜色，都可能影响远景清晰度。

“偏色”在这里描述的是可见的蓝绿／灰紫残留现象。由于缺少真实 clear 参照，尚不能给出每个区域的真实色差，也不能把所有蓝色都判成错误颜色。

### 7.2 问题二：远处高斯球残留

**表现：**去水后，远处水域或物体上方出现明显的椭圆斑块、拉伸的高斯片、半透明色团、条纹或尖细拖影。这些内容在带水渲染中可能被水体颜色和衰减遮住，去水后反而更显眼。

![Panama 远景偏色和远处高斯球残留定位](assets/project_overview_20260917/03_panama_far_problems.png)

**图 3：Panama 的问题定位。**红色 B 框对应右下的局部对比：带水渲染接近连续的蓝色水域，去水渲染则暴露明显的拉伸色块和细条纹。黄色 A 框则展示远景表面仍有青蓝覆盖。两种问题会共存，但不是同一件事。

本报告沿用用户的叫法，将第二类现象称为**“远处高斯球残留”**。严格来说，截图只能确认残留外观；它没有把每个斑块逐一反查到特定 Gaussian，也不能单凭二维图确认这些高斯的三维距离。可能存在以下情况：

- 某些高斯承担了本应由介质表示的颜色或低频背景；
- 远处表面证据不足，产生尺度过大、位置不稳定或多层重叠的高斯；
- 真实薄结构、遮挡边界和方向相关外观，在不充分的观测下被错误表示。

目前还缺少足够可靠的逐高斯归因，无法安全地区分“应该删除的残留”和“需要保留的真实远处结构”。因此，直接按距离、大小、颜色或低支持度剪掉高斯，可能同时删除真实物体。

### 7.3 黑区与上述两个问题有什么区别

当前 clear 渲染不会自动为没有物体贡献的方向补上一个自然背景，因此纯水域方向在移除介质后变黑，不一定是物体上的“洞”。另一方面，若真实物体区域覆盖不足，也可能出现有问题的黑区。

需要分别看待：

| 现象 | 直观含义 | 不能直接推出的结论 |
|---|---|---|
| 远处表面偏色 | 已有表面的颜色分解可能不充分 | 不能直接断言只需减蓝或提高曝光 |
| 高斯球／条纹残留 | 去水后显露不自然的高斯合成外观 | 不能直接断言所有相关高斯都应删除 |
| 纯水域变黑 | 去掉介质后该方向没有物体颜色贡献 | 不能一律视为几何空洞 |
| 物体区域出现黑洞 | 可能涉及覆盖、颜色或混合层问题 | 不能仅凭黑像素数决定增点 |

## 8. 远景诊断已经查清了什么

四场景冻结诊断覆盖 75 张训练图和全部 13 张测试图，模型参数保持不变。结果支持联合解释，尚不能把责任全部归于“深度”或“介质估计”。

| 场景 | 远景透射率 R/G/B | 远景颜色敏感度平方保留率 R/G/B | 宽松远景中深度分散较高的比例 |
|---|---|---|---:|
| Curasao | 0.336 / 0.338 / 0.356 | 11.2% / 11.0% / 12.5% | 10.8% |
| IUI3 | 0.280 / 0.285 / 0.292 | 8.5% / 8.6% / 8.9% | 51.0% |
| JapaneseGradens | 0.658 / 0.729 / 0.761 | 53.3% / 61.4% / 65.7% | 38.1% |
| Panama | 0.500 / 0.515 / 0.499 | 25.4% / 26.0% / 24.7% | 14.5% |

透射率是模型当前学到的贡献加权结果，不是水质标定值。“敏感度平方保留率”比较有水和零介质下渲染对高斯颜色的响应强弱，不等于“真实颜色还剩多少”。深度分散用相对标准差 `CV>0.1` 描述，也不等于错误几何比例。三列使用不同筛选集合，不能直接相乘或合成责任百分比。

![近中远景的逐通道观测强度](assets/project_overview_20260917/04_transmission_by_depth.png)

**图 4：距离分组与颜色观测强度。**近、中、远由训练视图的模型深度分段定义，并非统一的米制距离。Curasao/IUI3 的远景颜色约束衰减较强；JapaneseGradens 仍有较高透射率，因此不能统一归咎于“远处没有颜色信息”。

另外两项重要发现是：

- 对介质做小幅扰动后，简单的颜色响应可以抵消相当一部分图像变化。这支持颜色／介质存在局部歧义，但不能证明原介质参数一定估错。
- 稳定表面筛选后的重投影通过率较高，但把深度分散、较低覆盖区域纳入后，一致性明显下降，尤其是 IUI3 和 JapaneseGradens。不能只用最稳定的表面证明整个场景几何正确。

此前 DVS 还检查过“介质衰减阈值把已有高斯从 clear 中错误剔除”的假设。完整代码中的 `min(0, min(beta))` 使审计路径上的实际贡献截断退化为 alpha 阈值；26 组原始／零介质冻结对照的 clear 和覆盖逐位一致。**该特定阈值解释在已审计路径上不成立**，但这不排除其他几何或分解问题。

## 9. 已经尝试过哪些方向

下表按研究问题归类，避免把一个机制的多个参数设置算成许多个独立创新。具体历史数据见文末来源。

| 方向 | 代表尝试 | 实验状态与主要发现 |
|---|---|---|
| 限制相机介质自由度 | M1、OCMC、相关调度 | 有可保留的局部／配对收益，但无法单独保证真实介质恢复 |
| 跨视图颜色锚定 | CICA | 完成四场景归因；带水指标小幅改善，远景去水问题仍在 |
| 抑制或门控外观残差 | BRASH、BVAM、GRAC、GCRC、TABA、CRCC 等 | 多个实现和训练已有记录；收益常依赖场景，没有稳定解决整体问题 |
| 调整几何、占据与增删点 | capacity、cleanup、MPDR、伪深度表面约束等 | 清理残留与保留真实物体经常冲突；不能据此认定增加高斯数量就能修复问题 |
| 调整介质／背景归属 | M2、B_inf 约束、GMVC、光学深度和光谱约束 | 有局部正信号，跨场景和物体保留仍有风险 |
| 调整有界颜色表达 | FSB、SBR、FSB-alpha、分阶 D1、curriculum | FSB 保留；SBR 平均 PSNR -0.015784 dB，D1 相对 FSB -0.056910 dB，curriculum -0.018585 dB，均未替换 FSB |
| 梯度、角度和表面稳定性 | PGS、VAB、CVC | 完成相应冻结诊断，证据未支持进入所提方案的正式训练；不能称为完整训练失败 |
| renderer/CICA 导数一致性 | backward 修正、精确 FSB DC 导数 | 完成工程审计和共享前缀重复对照；CICA 导数修正未带来超过重复差的明确收益 |
| 终点介质校准 | 9 维介质输出校正 | 全图拟合平均 PSNR +0.08155 dB，clear 完全不变；仍有视图／区域退化，未证明跨重复稳定，也没有修复去水远景 |
| 最新远景专用尝试 | CDRC、LSPR、MST | 三者均已实际完成四场景 2k 续训，结果见下一节 |

MV-GAR/MCGR 的部分结论来自用户提供的历史说明，早期总表已标注当前工作树未独立核验的边界。本文不将其补写为此次重新运行并确认的结果。

这些探索说明，“再加一个 gate、颜色先验或几何损失”并不自动提供足够的新约束。另一方面，局部负结果也不能推出所有同类方法必然无效。

## 10. 最新 CDRC、LSPR、MST 实验

### 10.1 实际做了什么

按用户要求，三个候选直接进入实现与训练，没有因先前诊断未通过而停止。它们分别从同一场景的 FSB+CICA step-14999 状态分叉，各续训 2,000 步；另有两次同配置基线续训 `BASE_A`、`BASE_B`。

总计 20 路训练、40,000 次更新、65 次终态视图评估，覆盖全部 13 个不同测试视图。三个候选独立比较，没有叠加到一起。输入 checkpoint 和历史资产保持不变。

| 候选 | 本轮实现的想法 | 主要限制 |
|---|---|---|
| CDRC | 利用训练视图之间的跨距离对应，互相解释水下颜色观测 | 共享的是透射率加权有效颜色，未必等于单个真实表面的 clear 颜色 |
| LSPR | 用附近高信息高斯的基础颜色比例，约束弱观测高斯 | 邻近不保证相同材质；没有引入独立颜色观测 |
| MST | 对可见直达光的近／中／远层联合学习轻量散射模糊 | 是可见层卷积近似，不是完整多重散射；未引入真实 clear 监督 |

LSPR、MST 使用的是本轮训练前明确声明的工作定义，因为完整原始描述未在可用上下文中找到。结论限于这些实际实现，不代表缩写的所有可能解释都经过实验。

## 11. 目前可以确定和不能确定的事情

| 可以确定 | 仍不能确定 |
|---|---|
| 前景去水的视觉表现通常好于远景 | 每个远景区域真正应当是什么颜色 |
| 远处偏色、模糊和高斯残留仍然存在 | 深度、介质、颜色各自承担多少因果责任 |
| 不同场景的观测衰减和深度分散程度明显不同 | 是否存在一个统一的全场景阈值能安全删除残留 |
| 带水拟合准确不等于物体／水体分解正确 | 仅靠当前照片能否唯一恢复物理真实分解 |
| 多个候选未稳定超过各自的严格对照 | 所有尚未尝试的颜色、几何或散射机制都无效 |
| BND/FSB 能限制高斯颜色范围 | 有界性本身足以保证真实去水或达到 SOTA |

目前的核心困难已经不只是“是否继续提高 PSNR”，而是**怎样在保留真实远处物体的同时，消除被高斯吸收的水体外观和不可靠占据**。偏色问题需要颜色／介质证据，高斯残留问题需要贡献来源和物体保留证据，两者不能仅用同一个亮度指标衡量。

## 12. 后续研究应满足什么条件

以下是后续设计原则，不代表已经完成的新实验：

1. **保留明确的参考模型。**继续以现有 FSB+CICA 的配对 checkpoint 为基础，单独记录带水指标和去水视觉变化，不以跨日期均值替代配对实验。
2. **先把“远景表面偏色”和“远水高斯残留”定位到不同区域与贡献。**特别关注 IUI3/JapaneseGradens 的混合深度区域，以及 Panama 图示中的远水斑块；不能把截图中的所有黑色或蓝色直接用作自动删除标签。
3. **修颜色时保留物体证据，清残留时保护真实结构。**任何删除、收缩或颜色传播都要说明其依据，检查物体边缘、薄结构和其他测试视图，而不只检查被放大的局部。
4. **将“提高带水拟合”和“改善真实去水”分别举证。**终点介质校准可能改善前者却让 clear 完全不变；增加颜色先验可能改变后者却损害前者。
5. **需要更强信息时明确其来源。**独立图像对应、标定、更多视角或外部先验都可能值得研究，但外部恢复模型并不是真实 clear GT，不能把教师偏好当成已知真值。

目前应保留已有可复现成果和负面证据，尚无理由把最新三个候选提升为最终方法，也不应通过曝光调整、简单减蓝或盲目删点来掩盖远景问题。
