# C1/C2 四场景扩展：冻结执行方案

2026-10-25（Asia/Shanghai）。用户要求在其余场景尝试 C1/C2，并最终给出四场景平均指标。
沿用 IUI3 已完成的 C1/C2 15k 结果，在 Curasao、JapaneseGradens-RedSea、Panama 各增加两条 raw 初始化、seed42、15k 训练，共新增 90,000 正式更新。独立作用于 B0，A 和 B 表面支持模块不叠加。

## 本次掩码复核

前轮只尝试了全视角共用的右上矩形，其他场景未获准入。本轮逐训练视角查看全图、上半部裁剪、原分辨率候选区放大以及相邻真实训练视图，改用更小区域和部分训练视角。没有查看新增场景的 C 结果来选 mask。只读训练原图和继承的 COLMAP 注册轨迹，测试图只用于核对 split 名单；没有用测试 RGB 构造目标。

实际图名和像素框由 `prepare_open_water_C_extension.py` 固定；其余训练图用显式空 mask，状态为 `UNKNOWN_NO_SUPERVISION`。它们照常参与原生 RGB 训练，C hook 在该视角跳过。非空框及外扩 12px 内均无已注册轨迹；这只是与结构证据冲突的否决检查，不是“无轨迹即水”的规则。Curasao 排除了候选中有鱼的 MTN_1289/1305 等画面，Japanese 排除了右上方接近珊瑚的画面，Panama 仅保留三张顶部较窄水域。

这些是保守人工 O 先验和近似无限水柱假设，并非稠密几何真值。继承 COLMAP 可能曾使用历史测试相机；不声称本次重建了 train-only COLMAP。Panama 覆盖尤其低，必须报告实际触发次数，不能用四场景平均掩盖适用范围。

## 不变的实验设置

C1 对原生 tied B_inf/medium_rgb 的 masked Charbonnier 残差施加 medium 梯度；C2 额外对原生终端透射率施加 `-log(T_end)` opacity 梯度。各组上限为原组梯度范数的 5% 乘以日程强度。每四步一次，500 前关闭，500–2000 渐入，2000–8000 保持，8000–10000 退火，最后 5000 步关闭。不补偿空视角造成的低触发率，不按测试指标调强度或选 checkpoint。

本轮仅扩展 scene/asset 接口并允许明确标注的空 mask；非空 mask 的 loss/梯度算式不变。原生 forward、优化器、densification、CICA 和渲染后端保持一致。每个新增场景每臂 20 步一次性 smoke，检验实际路由及重载；smoke 不初始化正式训练。正式输出与历史实验分开存储。

## 汇总与完整性

主指标沿用原 worker 的 `metrics.py` 原分辨率 float PSNR/SSIM/LPIPS-VGG/MSE，先平均场景内测试图，再四场景等权平均；不将 13 张图混为单一平均。对照包括配对 B0、A010；同时保留各场景/逐视角和负结果。IUI3 从 `C_open_water_20261024` 引用，其他三场景从 `C_four_scene_20261025` 读取。

检查初始化、完整 15k 相机序列与 B0 一致性、完成更新数、checkpoint 文件哈希、finite 指标、C 实际触发和 5% cap。六条正式训练由 supervisor 持续记录 exit code，训练代码和 mask 哈希在启动前封存。GPU 进程显存按时间采样，只标记采样最大值，不冒称完整分配峰值。初始磁盘可用约 47GB，预计本轮 checkpoint 与渲染低于 12GB。

已有 IUI3 测试结果在本次扩展前已知，这属于探索性后续；不改已有强度/日程，不把本次四场景单 seed 结果当作独立重复或显著性验证。
