# 蓝绿色高斯残留：后续实验方案

日期：2026-10-21。状态：实验设计，尚未实施新模块或启动训练。

依据：`UNDERWATER_3DGS_LITERATURE_AND_NEXT_MECHANISMS_20261021.md`、原生职责迁移15k结果、SARG-v10、CDRC/LSPR/MST结果，以及最新BND ON四场景复跑。文献描述沿用调研文档的证据范围，本方案没有再次联网核验。

## 1. 目标与固定基线

主要目标是在原生clear中减少有跨视图证据的蓝绿色浮片、椭圆片和拉丝，同时保留真实远景结构；带水测试质量尽可能不降，提升为额外收益。减少高斯数量、降低蓝绿通道值、降低opacity均不是独立成功条件。

固定基础：M1 + OCMC + CICA + BND ON；FSB OFF，Auxiliary/RAOC/MDRR及其他创新模块OFF。保留corrected_v1 renderer、原生forward、数据和相机、RGB loss、优化器及原始refinement规则。所有正式训练从原始COLMAP和随机介质初始化开始，每场景15,000次更新，seed 42。CICA从10,000步启用并沿用已有校准和刷新规则。不得混入额外的补偿更新。

最新参考目录：`research_runs/bnd_on_baseline_scratch15k_20261021_v2`。其四场景PSNR宏平均29.904876。现有CSV的LPIPS来自worker内部实例；若以项目metrics.py为统一口径，必须从最终checkpoint原生浮点输出重新评估基线与全部候选，不能只给候选换口径。PNG只能用于展示。任何新接线若改变随机调用、相机顺序或baseline实际更新，须另跑同入口关闭模块的配对B0。

## 2. 先建立可复核的残留评估资产

仅利用训练图和baseline训练视图clear建立固定资产，测试图不得用于mask制作、超参数选择或checkpoint选择。每场景预设至少3个不重叠残留区域，以及2个真实结构保护区域；面积、真实相机覆盖和可用对应不足时如实报告，不凑数。

区域分为：O可信开放水域、F真实表面前方浮层、S真实远景表面自身偏色、U未知混合。O需要原图和多视角核查；F需要独立于当前渲染深度的结构/自由空间证据。S不能按水体删除；U不接受强占据惩罚。模型自身深度、蓝色和低支持均不能单独决定标签。标签附证据、置信度、相机ID、像素范围；无可靠证据则保留为未知。

冻结主导来源诊断：按原生clear的实际合成贡献追踪ROI的主要高斯及后层。对前80%累计贡献来源做分组遮蔽可视化，并检查多视角对应，区分主导浮层、后层替代和表面偏色。该80%只是诊断覆盖目标，不能把对应高斯自动列为删除名单。

主要观测是固定原分辨率全图、ROI及真实相机序列中的残留形态和结构保持。可量化辅助项包括固定O/F区域的投影异常覆盖、O区域物体累计占据、可信表面前自由空间占据、保护区域边缘与带水误差；必须说明标签或几何先验依赖。蓝绿比例、球数、clear MAE和模型深度floater mass仅作诊断。跨run高斯ID不对应，不能用baseline ID名单直接评估新模型。

训练视图内固定发现/验证相机划分；验证相机不参与新模块的辅助目标构建，但仍可参加正常RGB训练，因此不是未见测试集。已有测试集被长期观察，最终结果属于固定基准复验，不宣称全新盲测。

## 3. 第一优先：A，形成期几何梯度分流

### 假设

介质合成残差会推动已有高斯的中心朝水体代理方向移动。有限抑制这部分不稳定更新，可能减少浮片形成；它不提供真实clear颜色标签。

### 最小实现

第一轮只改中心means更新，不改scale、rotation、opacity、SH、出生评分、剪枝或forward。定义原生direct与medium（含tail）输出，并用同一原始RGB损失伴随r计算：

```
g_d = (dI_direct/dmeans)^T r
g_m = (dI_medium/dmeans)^T r
g_native_rgb = g_d + g_m
```

r必须来自原有完整RGB损失，包括其图像级和强度归一化链式依赖；不能用单独分支拟合GT。非RGB项保留原梯度。direct仍含衰减，medium含真实深度/遮挡信息，不能称二者为真假几何标签。现有CUDA若忽略某输出伴随，须补接该VJP后再实验，不能用detach伪造分流。

以具有可信真实视图结构支持的高斯为作用域，其余保持原更新。第一版使用保守的有界抑制：

```
q = ||g_m|| / (||g_d|| + ||g_m|| + eps)
g_A = g_other + g_d + (1 - eta(t) * q) * g_m
```

q是优化诊断，不是水体概率；detach后使用。eta上限0.25，因此始终保留至少75%的medium梯度。首轮不再引入符号冲突门、scale loss或新深度loss，避免同时改变多个机制。若结构支持覆盖很低，仍可完成有限试验，但不能将其解释为全场景机制检验；下一步应改善支持证据，而不是把未知区自动纳入。

时间表：0–500普通训练；501–2000线性增加eta；2001–8000保持；8001–10000线性归零；10001–15000完全普通更新。只修改送入means Adam的梯度，Adam一阶/二阶矩正常累积，不恢复旧optimizer。记录实际中心位移、矩状态及尺度归一化位移分布，监测更新尖峰和结构损伤；首版不额外引入Adam后位移缩放，以免成为第二项干预。

### 有限工程验证

先用小合成场景检查中心VJP，再用每场景2张训练图核验分支和。要求归一化L2误差<=1e-3；近零梯度用绝对误差，阈值由FP32重复与有限差分稳定区间确定并提前记录。仅核验本轮改动路径，不重复历史全部审计。关闭模块应还原相同forward和原梯度；短程同RNG训练允许已量化CUDA非确定性误差。新预条件梯度是有意改变的优化策略，不要求其等于原loss有限差分。

四场景每场景最多20次真实smoke更新，使用一次性状态提前触发开/关及退火；不计正式预算、不转为正式初值。检查means实际变化、其他参数路由、Adam状态和保存恢复，并实测耗时/显存。明确实现错误修复；低覆盖或没有收益属于科学结果，不无限扩大准入审计。

## 4. 第二优先：B，可信表面支持约束

A完成后独立验证B，不默认与A叠加。先使用真实训练匹配及COLMAP；稠密预测只作带置信度的额外先验，须通过真实相机重投影和遮挡核查。没有支持的区域不施加表面约束。

第一版只增加不确定度归一化的中心到支持面距离惩罚，使用稳健Huber和有限附加梯度。第二版再单独消融法向厚度`n^T Sigma n`；二者不得首轮捆绑。支撑应覆盖实际footprint，不能因接触一个锚点就保护整个大球。仅对可信表面前方自由空间考虑占据约束，不惩罚遮挡后的未知空间。

辅助项每4步一次；初始梯度范数不超过对应原始几何梯度的5%，每个支持样本按不确定度与有效数量归一化。启用/退火时间沿用A，目标构造不用测试图。覆盖不足或先验错误须报告；不能用更强loss补足错误先验。

远景容量重分配留作B的后续独立开关：仅在可信表面且物体侧残差支持充分处调整增密，保持总出生预算匹配；不能对全部远处或蓝色区域逆透射增密。先确认表面约束有效，再开该消融。

## 5. 第三优先：C，可信开放水域原生介质监督

C单独加在B0。只对O区域施加训练期先验：medium-only原生反事实拟合真实带水观测，以及小权重物体累计占据压力。不能用完整模型的medium分量冒充无高斯反事实，也不能再叠一层alpha混合。近似无限水柱时才使用B_inf；若现有renderer不能构造一致反事实，须明确实现后再运行。

拆为C1（medium-only监督）和C2（C1+占据压力），用来判断直接介质监督是否足够、占据压力是否造成损伤。完整原生RGB loss持续存在。新增介质/opacity梯度分别上限为对应原梯度范数的5%；使用分组梯度上限，不能把小组梯度通过全局范数掩盖。时间表与A一致，每4步一次，仅采样已核验开放水域。未知混合区权重为0。

开放水域缺乏可靠mask的场景标记不适用；不得因需要四场景结果而制造mask。C不承担S类真实远景表面去色任务。删除前层后须追踪后层贡献，防止只把蓝绿色职责移到更深高斯。

## 6. 训练矩阵与预算

按阶段执行，各阶段保留终点负结果并完成评估。正式训练前封存配置、代码哈希、相机序列、ROI、阈值及预算；不以测试指标选择提前停止点。

| 阶段 | 分支 | 场景与训练 | 新增正式更新 |
|---|---|---|---:|
| A主检验 | 同入口B0、A(eta=.25) | 4场景，各从零15k | 120,000 |
| A强度消融（仅验证相机显示可见收益且结构安全时） | A(eta=.10) | 4场景，各从零15k | 60,000 |
| B主检验 | B中心支持约束 | 4场景，各从零15k；无支持场景仍报告覆盖 | 60,000 |
| C主检验 | C1、C2 | 有可信O区域的场景，各从零15k | 最多120,000 |

首批只执行A主检验，8组共120,000次更新。已有baseline作为参考；关闭模块的配对B0用于消除新入口和随机路径差异。后续阶段为条件预算，不默认一次启动全部；A失败不自动阻止针对不同区域的B/C独立检验。

最终选定候选后增加seed 43、44，同入口B0/候选、四场景各15k，共240,000次更新。两个新增seed仍是有限复验，应同时报告每个seed和场景，而非只报告总体均值。

## 7. 预注册判断规则

以下为工程筛选容差，不是统计显著性或真实clear精度保证。

- 带水保护：相对本轮配对B0，四场景平均PSNR下降不超过0.05 dB；任何单场景下降不超过0.10 dB；宏平均SSIM下降不超过0.001，LPIPS增加不超过0.002。PSNR提高但明显破坏结构或感知质量仍不晋级。MSE一并报告，不能由平均PSNR替代。
- 残留改善：在有可靠标签的固定O/F区域，至少3/4场景出现跨至少3个有效真实相机的可见形态改善，并使可适用的异常投影覆盖或自由空间占据相对降低至少20%。原始量接近0或标签不适用时记N/A，不计算虚假大百分比。少于3个场景有可靠区域时，只能形成局部结论。
- 结构保护：固定真实表面区域不得新增明显孔洞、切掉物体或将多层表面压成一层；同时报告区域带水误差与边缘代理。无法确认的视觉差异标为不确定，不计成功。
- 晋级需要残留和带水保护同时成立。0.01 dB级别单seed改善不构成质量提高的证据；多seed最终平均PSNR为正且无系统性单场景损伤时才描述为一致正向趋势，显著性需另行分析。

阈值须在候选结果可见之前封存。验证相机可用于决定是否执行下一阶段，测试终点评估只报告；若测试结果影响下一轮设计，下一轮需披露该探索性依赖。

## 8. 交付与存储

每个分支交付：配置/代码哈希、真实开关和梯度审计、每场景与逐视图浮点PSNR/SSIM/LPIPS/MSE、固定全图/ROI拼图、真实训练相机序列视频、主导及后层贡献诊断、参数/高斯数变化、实际单步耗时/峰值显存/总成本、失败日志和恢复记录。clear只采用共同曝光和clamp显示，不做各分支独立白平衡、对比度或颜色修正。

原生forward不变只代表未新增推理算子，仍须实测FPS，球数和分布会改变速度。不能宣称训练零开销。

当前磁盘余量约58 GiB，仅为前轮结束时快照。正式启动前重新检查，按四场景配对预算估算空间；默认保存小型初始状态和最终完整checkpoint，必要中间恢复点滚动保留。冻结ROI和最终测试视图保存float；全相机序列优先流式编码视频，避免完整事件快照。只清理本轮明确标记的可再生临时资产，历史实验不自动删除。

## 9. 推荐决策

首先完成固定ROI分类和有限A分支VJP接线，然后执行四场景B0/A配对从零15k。若A只改善指标却不减少主导残留，不保留为去残留模块；若A减少浮层但降低带水指标，先看结构支持及梯度诊断，最多做预定弱强度消融，不扩大opacity压力。B针对有真实表面支持区域，C针对明确开放水域，各自独立验证。真实表面自身偏色S需要额外颜色/光学可辨识证据，不承诺通过几何删除解决。
