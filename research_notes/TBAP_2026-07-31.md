# Transmission-Balanced Appearance Preconditioning Audit

Date: 2026-07-31
Branch: `refactor/core-framework`
Base commit before this work: `19b0414 Add renderer color bias audit diagnostics`

## Goal

This pass tested the GPT-proposed Transmission-Balanced Appearance Preconditioning (TBAP) mechanism before launching any 1000-step training pilots.

The causal question was:

```text
Does forward attenuation suppress far Gaussian appearance gradients enough that
an appearance-only, inverse-transmission-weighted auxiliary path can selectively
restore far clear-color gradients?
```

Per the plan, the experiment must first pass a single-batch gradient gate:

```text
farthest 25% Gaussian DC gradient: 1.5x to 3.0x
nearest 25% Gaussian DC gradient: <10% change
total appearance gradient: <=1.5x
red gradient: recovers relative to G/B
no NaN/Inf
```

If this gate fails, the P0-P3 1000-step pilots should not be run.

The forward path remains unchanged. TBAP adds a training-only auxiliary render:

```text
xys, depths, radii, conics, opacities: detached
medium_rgb, medium_bs, medium_attn: detached
colors: differentiable
```

The TBAP prediction is numerically equal to the physical render:

```text
I_tbap = stopgrad(I_main) + I_object_proxy - stopgrad(I_object_proxy)
```

Thus the auxiliary loss can only update Gaussian appearance.

### Pixel Weight Diagnosis

IUI3 strong farthest-pixel bin:

```text
support mean: 0.1332
transmission mean RGB: 0.414 / 0.227 / 0.233
normalized weight RGB: 0.823 / 1.122 / 1.146
```

The learned attenuation says G/B transmission is lower than R, so inverse-transmission weighting boosts G/B more than R. This is opposite to the desired red-gradient recovery.

Japanese stronger farthest-pixel bin:

```text
support mean: 0.0986
transmission mean RGB: 0.069 / 0.087 / 0.081
raw weight RGB: 5.000 / 4.990 / 5.000
normalized weight RGB: 1.122 / 1.147 / 1.132
```

Here the raw weights saturate at the cap, so per-channel transmission differences largely disappear. The final far gradient is still B > G > R because the residual and rendered appearance terms dominate.

## Decision

Do not run the P0-P3 1000-step pilot yet.

Reason:

```text
The single-batch gate does not pass on IUI3.
```

At low lambda, TBAP is much too weak. At strong lambda, IUI3 reaches the total appearance-gradient limit before the farthest Gaussian DC gradient reaches 1.5x:

```text
IUI3 strong:
  total appearance ratio = 1.507
  farthest DC ratio      = 1.166
```

JapaneseGradens can be forced through the farthest mean-DC gate with lambda 3.5:

```text
Japanese stronger:
  total appearance ratio = 1.290
  farthest DC ratio      = 1.568
```

But it still fails the red-recovery requirement:

```text
far R/G/B ratios = 1.363 / 1.606 / 1.840
```

Thus the mechanism is not doing the intended physical correction. It either boosts the wrong channels because the learned attenuation spectrum is not reliable, or saturates the inverse-transmission weights so the residual itself determines channel direction.

## Conclusion

TBAP, in its current form, is not a validated training module.

The audit supports a narrower conclusion:

```text
The far-color-cast problem is not solved by simply preconditioning Gaussian
appearance gradients with the learned medium transmission.
```

The key failure mode is channel direction:

```text
IUI3 learned transmission gives lower G/B transmission than R in the far bin,
so inverse transmission amplifies G/B gradients rather than recovering red.
```

This connects directly to the renderer color-bias audit: the learned medium parameters already have strong spectral violations, so using them as the source of an appearance-gradient preconditioner can reinforce the wrong channel direction.

## Next Step

Do not spend GPU on P0-P3 until the preconditioner source is revised.

The next causal test should isolate color-gradient conditioning from learned medium spectral errors. Reasonable candidates:

```text
1. Use scalar/luma transmission for TBAP support and magnitude, not per-channel learned transmission.
2. Use a bounded or monotonic medium parameterization before using transmission as a preconditioner.
3. Test a residual-only DC color correction with medium frozen and scalar far support, independent of learned channel ordering.
4. If scalar conditioning still fails, move away from single-color Gaussian appearance toward intrinsic/degraded dual-color representation.
```

Do not reintroduce:

```text
Surface/Hybrid renderer rewrite
tail/TMICA expansion
old M2 ownership mix
hard spectral channel-order loss
opacity decay or hard pruning
```
