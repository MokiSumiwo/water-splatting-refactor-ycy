# TMICA: Tail-Guided Medium-Invariant Clear Appearance

Date: 2026-07-31
Branch: `refactor/core-framework`

## Goal

This experiment changes the current priority from far-water Gaussian removal to far-distance clear-appearance color cast.

TACMD showed that tail evidence is useful as a water-color direction, but directly optimizing BS band, finite BS convergence, or counterfactual underwater RGB does not stably improve `J`. TMICA therefore uses tail only to build a detached water-color axis and applies the active loss directly to far-object clear appearance:

```text
tail evidence -> detached water-color axis -> far-object J water-axis suppression
```

The implementation keeps the main physical renderer and inference output unchanged.

Key behavior:

1. Reuses TACMD tail evidence to estimate a strict detached tail anchor.
2. Adds quality gates for support coverage, tail chroma variance, border contact, and scene EMA consistency.
3. Builds a detached water-color axis in CLR / log-chromaticity space.
4. Uses differentiable `J_proxy_raw` for training because the historical main-render `J_gaussian_raw` path has inactive or incomplete Gaussian gradients.
5. Forces TMICA proxy training to be appearance-only by detaching proxy geometry and opacity whenever TMICA axis loss is active.
6. Optionally projects clear-image gradients onto the detached water-color axis and removes luma by subtracting channel mean.

## Interpretation

1. R1 tail-lite alone is not viable. It either has little useful color-cast effect or greatly increases accumulation / water residuals, especially on JapaneseGradens.
2. Direct far-object J-axis pressure is a real and strong signal. R2/R3 reduce J Blue by 70-88% depending on scene.
3. The current axis weights are too aggressive for a formal replacement. IUI3 R2/R3 miss PSNR by 0.15-0.21 dB and reduce object accumulation retention to 0.94/0.93. JapaneseGradens R3 is closer, but still misses the PSNR gate and increases Far Clear.
4. Tail-lite plus axis is not uniformly better than axis alone. IUI3 R3 improves Far Accum and Water Accum over R2, but worsens PSNR and object retention. JapaneseGradens R3 improves PSNR and Far Accum over R2, but still increases Far Clear.
5. Half-axis R4 preserves IUI3 object accumulation, but Far Accum and Water Accum regress. It is not the right trade-off.

## Current Conclusion

TMICA validates the new direction: directly constraining far-object clear appearance along a detached tail water-color axis is much more aligned with the current far-distance color-cast problem than TACMD's medium-parameter objectives.

However, this first implementation should not replace M1. It is a strong mechanism probe, not a final model:

```text
Best color-cast candidates:
  IUI3: R2 axis, R3 tail+axis
  JapaneseGradens: R3 tail+axis

Formal replacement status:
  Not passed. PSNR and/or retention still fail.
```

Recommended next step is not to increase TMICA weights. Instead:

1. Test lower far-axis weights: `5e-5`, `1e-4`, with trend/overcorrection scaled down proportionally.
2. Keep `lambda_tmica_tail_lite=0` for the first follow-up because R1 is consistently harmful.
3. Add an object-safe support diagnostic before any new full run: mean support on far object, near object, and water masks.
4. Consider disabling `tmica_use_sensitivity` or reducing `tmica_object_accum_mid` only if support maps show object over-coverage.
5. Keep proxy appearance-only behavior; do not re-enable geometry or opacity gradients for this color-cast objective.
