# SARG-v5 同光线分段实验结果

两场景均从 COLMAP 初始化完成15000次更新（0..14999），seed42，corrected_v1+BND+M1+OCMC+CICA，无failure。最终checkpoint、completion.json、final_roles、原生指标及只读后处理齐全。训练源文件哈希与启动记录一致；重载PSNR复核通过，诊断前后模型哈希一致。

设计见 `SARG_V5_SAME_RAY_DESIGN_20261015.md`。v5独立CUDA探针沿同一像素光线分配对象贡献，并对介质区间积分求交拆分；删除前后采用完整模型固定区间。解析测试、两个2步smoke、两个冻结模型全刷新均通过。未修改原生训练前向/反向。

PSNR按逐视图dB平均，因此IUI3平均PSNR略升而平均MSE由0.00152672升至0.00158998，不矛盾。Panama平均MSE降至0.00071054。没有无水GT，颜色比例不等于语义水体/真实颜色误差。固定远景与既有baseline掩码严格配对（覆盖>0.8、支持深度最高30%）；自身远景为各模型深度上三分位，模型间支持域不同。

视觉检查：Panama上缘蓝灰色团块仍明显，v5未改善主要残留；IUI3若干局部色偏变化，但珊瑚上缘蓝色帘状/雾状残留仍明显，不能声称整体去水体改善。锚点覆盖略低，不能证明无结构损伤。只有seed42和少量测试视图（3/4），不作跨种子显著性结论。

## 责任与删除

最终单组候选均72组，Panama接受19组，IUI3接受5组。有效最远段 residual p10/median/p90：

| 场景 | 全部候选 | 接受组 | 活跃探针缺失最远段（全部/接受） |
|---|---|---|---|
| Panama |0 / 0.647 / 0.947|0 / 0.519 / 0.898|19 / 4|
| IUI3 |0.649 / 0.931 / 0.979|0.739 / 0.864 / 0.949|48 / 1|

缺失远段赋0责任参与门槛，不纳入有效段分布。residual=1-r；门槛r>=0.08仍宽松，特别IUI3接受组替代不充分。v4和v5分段定义不同，不直接将其residual数值作收益比较。

删除最终water组：Panama固定远景clear平均绝对变化0.000320，带水MSE增加7.55e-6；IUI3为0.0000180、+7.15e-6。尤其IUI3对远景影响仍小，说明最终已识别组不能解释主要残留；强删这些组存在重建代价。

## 判断

实现层面：同光线对象/介质分段机制已实现并经原生重放守恒验证。
目标层面：去除远景蓝绿色高斯残留仍未通过两场景一致验证。不能将原生重建指标改善当作去水体成功，也不建议直接加大惩罚或盲目长训。

下一步应冻结v5，对可见残留的实际贡献高斯做覆盖率审计：区分被锚点保护、未进入72组预算、缺少跨视角支持、远段低替代和已接受但后续重建补偿。独立研究真实结构保护及中位数门槛的高残差尾部。此轮没有自动启动额外训练。
