# SARG 残留高斯与后续去水体模块设计分析

## 1. 要解决的问题

当前目标不是继续提高带水体图像的 PSNR，而是减少去水体/clear 渲染中的远景蓝绿色片状、拉丝状高斯残留，同时保护真实物体的几何、边缘和跨视角一致性。数据没有无水清晰图像真值，因此“蓝色更少”不能直接等同于去水体成功；必须同时审计水下重建、clear 变化、局部误差、深度/锚点支持和多视角稳定性。

v5、v6 扩展到四场景后的带水体平均结果仍然接近：v5 PSNR 29.9002，v6 29.9191；v6 只高 0.0189 dB。四场景平均低于预期 30 dB，说明当前 SARG 主要改变的是少量局部候选责任，而没有改变整体重建容量或解决远景残留的主导成因。该结果不应被解释为去水体失败的唯一证据，因为带水指标和 clear 质量是不同目标。

## 2. 残留高斯的实测性质

### 2.1 它们是训练重建中的有效成分，而不是简单的“无用蓝点”

Panama MTN_1529 的远景蓝绿色 ROI 中，最终模型约 1,098,511 个高斯里，前 509 个承担约 50% 的 additive clear RGB 贡献，前 14,427 个承担约 80%，前 12 个已经承担 10.21%。前 509 个的平均 alpha 约 0.734。对这 509 个在全部 15 张训练视图做反事实重渲染：alpha 降低 10% 会在 11/15 视图增加全图 MSE，完整删除会在 15/15 视图增加 MSE；仅前 12 个降低 10% 也有 3/15 视图 MSE 上升。说明训练集确实依赖这些高斯来重建观察到的水下 RGB，但这只能证明“当前模型的成像责任依赖”，不能证明它们是真实物体，也不能证明它们是水体。

### 2.2 对象、介质和遮挡责任发生了混合

当前模型把一个高斯作为 object branch 的辐射源。它可以同时承担真实远处表面、局部散射、雾状颜色、遮挡边界和水下外观补偿。模型没有一个显式的每高斯 object/medium 双成分变量，因此训练只看到最终水下 RGB，无法唯一决定“这部分应由高斯表示”还是“这部分应由介质表示”。蓝绿色、低纹理、低对比、远距离区域尤其容易出现这种分配歧义。

Panama 的 MTN_1534/1544 等训练图中，远景本身就是蓝色且结构不清楚；对优化器而言，一个带蓝色外观和遮挡作用的高斯是很便宜的解释。即使它在 clear 渲染中显得像水体残留，删除后也会形成错误颜色、空洞或边缘误差。部分高斯还可能跨越真实表面和介质状区域，单个椭球无法被赋予纯粹语义角色。

### 2.3 它们具有明显的多视角、视图依赖和深度层性质

- 高贡献残留并非只在一个视角出现；可见性、alpha 和颜色贡献在视图间变化。
- 同一远景区域中，近层高斯的遮挡会改变远层高斯的可见性；直接删除远层不能只看单像素颜色。
- v5 的同光线分段责任探针已能按实际排序的 Gaussian 和介质区间重放，但最终接受组对主要残留的覆盖仍很低，说明“责任计算正确”不等于“候选覆盖足够”。
- 单高斯诊断显示两种情况同时存在：有些组失败来自组内混合，拆成 singleton 后出现稀疏安全尾部；但多数高贡献组在 singleton 后仍会失败，说明很多成员自身就与物体/遮挡纠缠。

### 2.4 锚点保护既保护真实结构，也可能保护混合高斯

Panama 1529 ROI 的锚点保护贡献约 35.15%，v5 覆盖审计中按不同固定远景口径保护贡献约 52%–60%；历史 SARG 准入只覆盖约 3.67%，最终 water 角色覆盖甚至只有约 0.565%（Panama）和 0.011%（IUI3）的固定远景蓝绿 additive 贡献。保护高斯不能直接删除是合理的，但“高斯与任一锚点相交即整球保护”的二值规则可能保护了同时延伸到水体状区域的混合支撑。解除保护尚没有证据；需要拆分/几何收缩/屏幕支持级保护，而不是简单取消 anchor gate。

### 2.5 重要残留没有进入候选池，或被预算截断

v5 覆盖审计显示：固定远景蓝绿贡献中，Panama/IUI3 最终接受联合仅约 0.49%/0.002%；符合条件但未进入最终测试约 38.63%/34.95%；小于 8 成员的空间格子直接被丢弃，约占合并贡献 18.23%/21.62%。未测试集合的 clear 反事实影响明显大于已接受集合。因此当前瓶颈首先是候选生成、实际贡献覆盖和预算分配，而不是抑制强度不足。

## 3. Water-splatting 的实际渲染方式

当前渲染不是“先渲染物体，再覆盖一张水体图”。它沿每条像素光线按深度从前到后处理排序后的高斯。

对第 i 个高斯：

```text
alpha_i = min(0.999, opacity_i * exp(-sigma_i))
vis_i   = T_i * alpha_i
T_{i+1} = T_i * (1 - alpha_i)
```

其中 `T_i` 是到达该高斯前的透射率，`sigma_i` 来自二维椭圆 footprint。高斯对象颜色 `J_i` 同时产生两部分：

```text
object_i = vis_i * exp(-beta_att * depth_i) * J_i
```

介质后向散射在每两个相邻深度之间积分：

```text
medium_interval = T_i * B_inf_or_medium_rgb *
                   (exp(-beta_bs * z_prev) - exp(-beta_bs * z_i))
```

最后还有从最后一个高斯到无限远的 medium tail，并按 `b_inf_mode` 可能使用绑定的无限远颜色。最终输出近似为：

```text
pred = sum(object_i + medium_interval_i) + medium_tail
```

代码中对应输出包括 `rgb_object`、`rgb_medium`、`rgb_tail`、`J_gaussian_raw`、`rgb_clear` 和 `pred_image`。`J_gaussian_raw` 是未经过介质衰减的高斯 additive clear 贡献；它不是无水真值，只是物体分支的反事实输出。

这个结构带来三个后果：

1. 高斯颜色可以被介质衰减，但高斯仍是 object branch 的源；没有显式机制把该源的辐射重新分配给介质。
2. 删除/衰减高斯不仅改变颜色，也改变 `T`，从而改变后续高斯和介质的权重，可能造成空洞、边缘损伤或远层显露。
3. 介质是按像素/相机条件预测的连续场，不能自动生成某个局部高斯原本提供的遮挡轮廓和细粒度空间纹理。

因此，直接压低 opacity 不是纯颜色编辑；它是对光线传输和遮挡的干预。固定几何外观的中性化实验只能说明颜色可被改变，不能说明真实水体成分已被分离。

## 4. 已经尝试的策略与结果

### SARG-v1/v2/v3：表面责任、远场和初始代理

早期版本使用表面锚点、深度/尺度/远场先验、SH 或 opacity 代理和跨视图责任。结果没有形成稳定的 clear 改善；这些代理不能判断介质是否真的能接管高斯贡献。主要问题是把“远、蓝、低纹理、无锚点”当作水体证据，证据强度不足。

### SARG-v4：分段责任

v4 引入对象/介质分段残差和同光线责任概念。早期实现按最终像素深度分箱，不能真正拆分同一光线内各高斯贡献；之后修复并使用真实排序/深度区间探针。探针守恒误差达到约 1e-6 量级，说明实现可靠，但接受的高斯覆盖主要残留很小，最终删除影响也很小。v4 不是因为渲染分段错误而失败，而是分段证据没有形成足够的可安全候选。

### SARG-v5：同光线对象—介质分段 + 候选分组

v5 用独立 CUDA 重放沿同一光线累积对象贡献和介质区间积分，检查删除后介质是否替代对象贡献。Panama 接受 19 组，IUI3 接受 5 组；固定远景 clear 变化仅约 0.000320 和 0.000018，且删除带水 MSE 分别增加约 7.55e-6 和 7.15e-6。主要残留没有被覆盖。结论是责任探针有效，但 group/预算/锚点/小格子筛选漏掉了主要贡献。

### v6：允许小组准入

允许 1–7 成员小组，降低小组最少视角要求，保留其他安全门限。冻结验证中小组覆盖提高，且两场景独立视角联合审计更稳；但没有证明 clear 视觉收益。两场景 15k 的 v6 只是轻微改善带水指标；扩展到四场景后平均 PSNR 29.9191，v5 为 29.9002，差异仅 +0.0189 dB。小组准入解决了部分小组漏检，不解决高贡献高斯自身与物体的混合。

### v7：严格残留贡献排序 + 小组化 + 视图预算

v7 使用训练视图中的真实 additive contribution 排序，限制单组/全体的逐视图预算，并使用留出训练视图做审计。安全接受覆盖比简单策略更少；IUI3 仍有独立相机局部失败。说明真实贡献排序能找到更大候选池，但高贡献不代表可安全删除，且联合 bounding-box 会稀释局部错误。

### v8：信任预算

v8 试图改善预算与小组准入。训练有效完成，但 Panama/IUI3 clear 中远景蓝灰片状和蓝雾仍明显；最终候选对固定远景的实际影响很小。原生水下指标没有形成一致改善。v8 的失效主要是可操作候选覆盖不足，且梯度校准下限使名义 opacity 压力与实际目标不一致。

### v9：分阶段覆盖与预算

v9 增加多视图候选池、历史候选复核、小组递归拆分和分阶段衰减。但累计预算以当前 alpha 相对首次 alpha 的漂移估计，受到原生训练变化污染：预算很快超过上限，后续候选大多在 budget 阶段拒绝，实际非零 SARG 压力只持续约 998/499 步，最终有效准入为零。这个版本不能证明分阶段覆盖无效；它证明预算必须区分原生优化漂移和 SARG 增量影响，并需要回退/退出机制。

### 冻结局部分组与高贡献拒绝组拆分

局部贡献分组提高了 tested coverage（Panama 13.035%，IUI3 15.625%），但加入严格局部 photometric veto 后两场景均为 0 组准入。高贡献组拆成 2/4/8 和 singleton 后，Panama 仅 31/217 singleton 通过，IUI3 仅 5/105；IUI3 通过者的影响约 1e-7–1e-6，几乎没有有效去除量。结论是组混合和单高斯自身纠缠同时存在，不能只把 group size 调小。

### 单高斯多视角筛选与 opacity response

单高斯跨视角贡献筛选在 Panama 因锚点/得分过滤得到 0 候选，IUI3 得到 6 个但全部局部审计失败。单独 opacity response 中，10% 衰减的局部失败随强度增加：Panama 17/120→56/120，IUI3 26/150→135/150（10%→100%）。只有极少数 singleton 在 10% 下安全，实际 signed clear removal 约 0.0018%–0.0092%，远低于大范围可视改善所需量。

### 固定几何外观解耦对照

保持几何和 opacity 不变，只把候选颜色向中性方向调整。IUI3 某个候选在 10% 下可同时通过安全门控并减少蓝绿色，但 Panama 没有候选满足安全且有用的收益。该实验只说明外观方向可改变局部颜色，不说明中性颜色是正确的无水颜色；它也没有利用水下观测反推出对象/介质双成分。

### 冻结透明度衰减、累计预算

10% 衰减在少数 singleton 上有小的安全区间，但重复衰减未被证明可累积。固定总衰减预算的 Panama 暂时选择 4 个候选、平均 audit RGB reduction 约 0.01105%，IUI3 选择 5 个但最终每成员支持检查失败。联合 support 检查容易掩盖成员级局部损伤；因此不能直接进入短程训练。

### 介质补偿与受限补偿

对冻结 Panama v9，目标高斯 opacity 临时降低 10%，只优化 medium MLP 和方向编码。无严格留出时，300 步介质补偿使训练平均 MSE 下降约 6.05%，目标视图 MSE 下降约 14.5%，说明介质确实能接管一部分被削弱高斯的水下 RGB 信号。但这是循环训练视图、可能过拟合，且 MSE 改善伴随 L1 变差；没有证明恢复了真实清晰结构。

严格 holdout 补偿中，单成员/小组都没有获得准入。无衰减介质优化控制自身就会改变全图/局部误差；候选补偿相对于原模型或控制组仍触发局部失败。SARG-v10 受限补偿将介质更新限制在信赖域并加入范围外/边缘保持，四组最终只有极小或无有效支持，0 个准入。结论：介质容量有局部接管能力，但当前介质参数化、观测和局部约束不足以安全恢复被移除高斯的贡献。

## 5. 为什么整体没有达到预期

1. **目标错配。** 训练 loss 是带水 RGB；去水体 clear 输出没有 GT。优化器会保留任何能降低带水误差的高斯，即使它在 clear 图中像水体。
2. **可辨识性不足。** 一张水下 RGB 可以由“真实表面颜色×衰减 + 后向散射 + 高斯遮挡”多种组合解释。没有清晰图、深度或语义约束时，object/medium 分解不唯一。
3. **残留是高贡献长尾，不是少数孤立噪点。** 约 509 个高斯承担 Panama ROI 50%，而真正安全可衰减的 singleton 尾部贡献极小。强压少量候选无法改变整体视觉；强压高贡献候选又破坏训练视图。
4. **遮挡的非线性。** 删除一个高斯改变 T，继而改变后续对象和介质，不能用 additive RGB 贡献线性相加预测删除效果。
5. **候选覆盖和预算不匹配。** 小格子、锚点保护、72 组上限和排名截断排除了大量实际贡献。v9 还把原生 alpha 漂移误算为 SARG 累计预算。
6. **局部门控比全图平均更严格也更真实。** 大组/全图 MSE 可能通过，但固定支持 tile 上会出现边缘或局部结构损伤；联合 mask 会稀释单成员损伤。
7. **介质分支的表达边界。** 当前介质主要是相机/方向条件的连续 RGB、attenuation 和 backscatter 场，能补偿平滑色调，但不能自然复现局部遮挡轮廓、细纹理、边缘和不同深度层的独立责任。
8. **训练阶段时序。** 默认每 100 step 做 refinement；前 500 step warmup 不 refinement；每 5 个 refinement 周期 reset alpha；10,000 step 停止 split，但之后仍可继续 cull。SARG 角色若不随 split/duplicate/reset 重新验证，会被原生拓扑漂移稀释或失效。v9 的预算也与这种漂移耦合。

## 6. 对下一模块设计的具体启发

不要再把下一个模块定义为“更强的删除 gate”。更合理的是把问题改写为**可学习、受约束的 object/medium residual decomposition**：

1. 对每个高斯维护 object responsibility 和 medium responsibility，而不是二值 water label。责任应由实际屏幕 footprint、深度层、跨视角 residual 和介质可替代性共同估计。
2. 训练时先学习一个冻结/慢更新的 residual medium source，允许它在局部空间和深度上表达被削弱高斯的平滑散射；普通 camera-conditioned global medium 不足以接管局部轮廓。
3. 采用双分支反事实一致性：保持原始水下 RGB；同时对 object branch 施加小幅 opacity attenuation，由 medium residual 只补偿 attenuation 产生的差异。补偿损失必须在留出训练视图上验证，并加入范围外与边缘保持。
4. 使用 additive contribution 作为排序和预算，但使用完整 rasterized counterfactual 作为最终梯度/准入依据；不能把 additive 贡献直接当可删除量。
5. 将 anchor 保护改为屏幕支持/轨迹保护：保护锚点附近的 object support，允许研究高斯的远离锚点部分，但不解除整个高斯的保护。实现上可能需要 covariance split、depth-aware footprint split 或独立 residual splat，而不是整球 opacity 删除。
6. 采用固定总预算并与原生变化分离：记录 intervention-free twin 或冻结 pre-intervention reference；预算只累计 SARG 造成的 alpha/clear 变化。每轮失败候选回滚并重新分配预算。
7. 分层候选覆盖：按残留区域、深度层、屏幕 tile、相机和贡献分桶轮转，报告“残留贡献覆盖率→实际受试覆盖→安全接受覆盖→有效去除量”四个比例。
8. 训练 schedule 上先做短程 pilot，观察 opacity rebound、责任转移、原生 pruning/densification 和 novel-view 局部损伤；只有冻结和短程都通过，才做 15k。
9. 评价必须分成三类：带水重建（PSNR/SSIM/LPIPS）、clear 反事实稳定性（局部/边缘/黑洞/颜色和覆盖）、责任解耦能力（被削弱对象贡献是否由介质 residual 在多视角接管）。没有 clear GT 时，不能用单一指标宣布成功。

## 7. 给 GPT 的核心问题

请基于以上事实设计下一代模块，而不是简单调 gate：

- 如何在现有 front-to-back Gaussian compositor 中增加局部、深度相关且可跨视角一致的 medium residual source，同时保持物体几何和 opacity 稳定？
- 如何定义可辨识的 object/medium responsibility，使它不会把真实远景蓝色表面误判为水体？
- 如何用冻结视图和留出视图建立可训练的 counterfactual supervision，并避免介质补偿过拟合带水 RGB？
- 如何处理一个高斯跨越真实表面与水体状区域的情况：拆分高斯、分配 residual splat，还是学习连续 responsibility？
- 如何让原生 densification/pruning 与责任状态同步，而不让原生 alpha 漂移污染 SARG 累计预算？
- 请提出明确的前向方程、损失、gate、schedule、回退条件和验证指标，优先解决“可见残留高斯覆盖不足 + 高贡献候选无法安全删除”这两个矛盾。

## 8. 最终判断

这些残留高斯最可能是**真实远景结构、局部水体散射、遮挡和训练集颜色反馈共同形成的混合表示**。其中一部分确实可能是介质本应承担但被高斯吸收的颜色；另一部分具有不可忽略的对象/遮挡责任；还有大量贡献因为锚点、分组和预算机制根本没有被测试。现有实验既不支持“全部是水体高斯”，也不支持“只要放宽 gate 就能删除”。

v5/v6 的主要经验是：同光线责任探针和小组准入提高了诊断可靠性，但没有产生足够的有效去除量。后续应从“删除高斯”转向“在保留几何的同时学习局部 object/medium 残差分解”，并以冻结多视角、留出视图、局部边缘保护和实际 clear 贡献覆盖作为先决条件。
